# Personal Developer Portfolio

Welcome to the repository of my personal portfolio website! This project showcases my background, key projects, technical skills, and contact information as a Software Developer.

**Live Demo:** [Check out my portfolio online]

---

## Key Features

- **🌐 Multilingual Support (i18n):** Toggle seamlessly between English and Portuguese.
- **🐱 Interactive Cat Face Component:** Fun custom component with eyes following the mouse cursor.
- **🎨 Modern UI/UX:** Clean, responsive design featuring a transparent dynamic navigation bar.
- **📱 Fully Responsive:** Optimized for desktop, tablet, and mobile displays.

---

## Tech Stack & Tools

- **Frontend:** React.js, JavaScript (ES6+), HTML5, CSS3 / Tailwind CSS
- **Build Tool:** Vite
- **Code Quality:** ESLint
- **Deployment:** GitHub Pages
